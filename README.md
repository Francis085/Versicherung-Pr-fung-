# §34d Übungsquiz

Lern-App zur Vorbereitung auf die Sachkundeprüfung Versicherungsvermittler (§ 34d GewO, IHK).

**Online nutzen:** https://francis085.github.io/Versicherung-Pr-fung-/
(GitHub Pages muss dafür unter *Settings → Pages* auf den Branch `main` eingestellt sein.)

## Funktionen

- 384 selbst formulierte Übungsfragen zu den Sachgebieten A–E, darunter Einfach- und Mehrfachauswahl, Kurzantworten und Rechenaufgaben
- Tagesrunde mit fälligen Wiederholungen und Fokus auf schwache Themen
- Fehlerheft mit Wiederholung in Abständen (1, 3, 7, 14, 30 Tage)
- Modi „Neue Fragen“ und „Schwierige Fragen“, Merkliste
- Prüfungssimulation mit Zeitlimit (Teil I / Teil II), Fragenübersicht, Markieren und Bestehensregel
- Fallstudien und Glossar mit Suche
- Statistik: Lernstand pro Frage, Sachgebiete, Aktivitätskalender, schwierigste Fragen
- Hell- und Dunkelmodus, Tagesziel, Prüfungstermin mit Lernplan
- Angefangene Runden lassen sich nach dem Neuladen fortsetzen
- Fortschritt wird nur lokal im Browser gespeichert und lässt sich als Code oder Datei auf ein anderes Gerät übertragen
- Einzelne HTML-Datei, läuft offline, kein Konto nötig

Hinweis: Keine Original-Prüfungsfragen und nicht das Proximus-Bedingungswerk. Zahlenwerte mit Stand 2026; Antworten bitte mit dem Kursmaterial abgleichen.
