# §34d Übungsquiz

Lern-App zur Vorbereitung auf die Sachkundeprüfung Versicherungsvermittler (§ 34d GewO, IHK).

- Rund 280 selbst formulierte Übungsfragen zu den Sachgebieten A–E
- Tagesrunde mit Fokus auf schwache Themen, Streak, Statistik, Prüfungstermin-Countdown
- Prüfungssimulation mit Zeitlimit (Teil I / Teil II)
- Fortschritt wird lokal im Browser gespeichert (localStorage)
- Einzelne HTML-Datei, läuft offline

Hinweis: Keine Original-Prüfungsfragen und nicht das Proximus-Bedingungswerk. Zahlenwerte mit Stand 2026.
